# 变更说明（2026-09-29）

## 1. 移除示例数据回退

- README 不再提及 `data/sample_data.csv`，更新目录结构和默认数据源说明。
- 抓取和导入命令说明 macOS/Linux 使用 `python3`、Windows 使用 `py`。
- `app.py` 默认只读取 `data/boss_jobs.csv`；可用 `ZOUYE_DATA_FILE` 指向其它真实岗位 CSV。
- 默认数据文件缺失时不再静默显示空看板，而是提示导入归档或指定有效 CSV。

## 2. 补齐抓取依赖

- 在 `requirements.txt` 加入 `websocket-client==1.8.0`。
- README 说明该依赖是 CDP 抓取脚本所需，并统一通过 `pip install -r requirements.txt` 安装。

## 3. 验证

- Python 3.9 下 `app.py` 语法编译通过。
- 看板、筛选选项、岗位列表 API 均返回 HTTP 200；看板总岗位数为 8274。
- 验证缺失数据文件时会输出明确的 `FileNotFoundError`，不再静默回退。

## 4. 性能和数据合并可靠性

- `app.load_data()` 增加进程内清洗结果缓存，使用路径、修改时间、变更时间、文件大小和 inode 检查数据源是否改变。
- 用线程锁保证并发请求遇到缓存未命中时只读/清洗一次；返回副本以避免调用方污染缓存。
- 上传数据重置时显式使缓存失效；默认 CSV 文件变化后下次请求自动重新加载。
- `merge_jobs.py` 不再静默跳过损坏或结构错误的归档；遇到错误时列出路径和原因并中止写入。
- 没有归档批次时也会明确失败，避免误写空 CSV。
- 新增 `tests/` 中的标准库 `unittest` 回归测试，覆盖缓存、并发、数据变化、薪资解析、去重、API 结果、空/缺失数据和归档错误。
- 验证命令：`python3 -m unittest discover -s tests -v`。
